# Upset (published site)

Live fantasy matchup scores, model win chances, free-play calls, and a research risk lab.
Open it: https://shaincarrasco.github.io/matchup/

This repo holds the built website for GitHub Pages. The source, tests, simulation results,
and development handoff are in the private `shaincarrasco/matchup-market` repo.

The current site uses non-purchasable, non-redeemable play coins. It does not accept real-money bets.
Projections use an unofficial feed during the beta.
